Presupuesto y factura: no son lo mismo

El presupuesto propone alcance, precio y condiciones. La factura documenta una operación realizada y solicita o acredita el pago.

Para qué sirve un presupuesto

Presenta al cliente servicios, cantidades, impuestos estimados, plazos y condiciones antes de aceptar el encargo. Conviene incluir fecha de validez y forma de aceptación.

Para qué sirve una factura

Documenta la operación e incluye número correlativo, fecha, datos fiscales, conceptos, impuestos y total. Un presupuesto no sustituye sus obligaciones formales.

Flujo habitual

1. Envías el presupuesto.
2. El cliente acepta.
3. Realizas el trabajo.
4. Emites la factura.

¿El presupuesto aceptado obliga?

Puede servir como prueba de las condiciones pactadas si identifica a las partes, detalla el trabajo y consta su aceptación.

Cómo convertirlo

Conserva cliente y conceptos, asigna el siguiente número de factura y revisa fechas, impuestos y trabajos realizados. No uses el número del presupuesto como número de factura.

Preguntas frecuentes

¿Un presupuesto lleva IVA?

Puede mostrar el IVA previsto para informar del total, pero no reemplaza la factura.

¿Hay que numerarlos?

Es recomendable para organizarlos, usando una secuencia distinta de las facturas.
