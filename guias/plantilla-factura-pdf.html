PLANTILLA GRATUITA

Crea una factura PDF editable

Rellena la plantilla en el navegador, revisa el resultado y usa «Imprimir / Guardar PDF». No necesitas registrarte ni subir información confidencial.

Usar plantilla gratis

Qué incluye la plantilla

  • Datos fiscales del emisor y del cliente.
  • Número, fecha de emisión y vencimiento.
  • Conceptos con cantidad y precio unitario.
  • Cálculo automático de IVA, IRPF y descuentos.
  • Notas, condiciones y forma de pago.

Cómo guardar la factura como PDF

Completa los campos y comprueba la vista previa. Pulsa «Imprimir / Guardar PDF». En la ventana del navegador elige «Guardar como PDF» como destino, revisa el formato y guarda el archivo con un nombre reconocible.

Privacidad por diseño: los datos se conservan localmente en tu navegador. La aplicación no dispone de un servidor que reciba el contenido de tus facturas.

Conserva una copia editable

El PDF es útil para entregar el documento, pero no para modificarlo después. Usa «Exportar copia» para guardar también un pequeño archivo JSON. Cuando necesites recuperar la factura, pulsa «Importar copia» y vuelve a editarla.

PDF frente a Word o Excel

Una hoja de cálculo ofrece flexibilidad, pero es fácil romper una fórmula o desplazar el diseño. La plantilla web mantiene los cálculos y la presentación separados. El PDF resultante es consistente y se abre en prácticamente cualquier dispositivo.

Lista de revisión antes de enviar

  • Comprueba nombres, identificadores fiscales y direcciones.
  • Verifica que el número no se haya usado antes.
  • Revisa los conceptos y los tipos de impuestos.
  • Indica vencimiento y forma de pago.
  • Guarda tu copia editable y el PDF enviado.
