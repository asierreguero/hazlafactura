# FacturaLista

Generador de facturas gratuito, privado y sin registro para autónomos. Todo el procesamiento y almacenamiento ocurre en el navegador.

## Funciones

- Facturas con múltiples conceptos, IVA, IRPF y descuentos.
- Vista previa inmediata e impresión/PDF.
- Persistencia local, exportación e importación de copias.
- PWA instalable y uso sin conexión.
- Cero backend, cero analítica y cero costes recurrentes.

## Desarrollo local

Sirve la carpeta con cualquier servidor estático, por ejemplo `npx serve .`, y abre la URL indicada.
